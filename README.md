# ios_helper

<video src="src/demo.mp4" controls width="800"></video>

一个用于 iOS 设备性能采集与分析的桌面工具，基于 PyQt5 + matplotlib 编写。

> 本项目依赖 [ios_device](https://github.com/your-repo/ios_device) 项目，请确保已正确配置 ios_device 环境。

## 功能说明

- 自动尝试连接本机的 iOS tunnel 服务
- 获取设备进程列表并支持选择目标进程
- 采集性能日志并写入本地 `.performance` 文件
- 实时展示帧率曲线和进程占用信息
- 支持对历史 `.performance` 文件做离线分析
- 退出时可将当前运行日志保存到 `log.txt`

## 启动方式

在当前目录下执行：

```bash
python realease.py
```

## 使用流程

1. 启动程序后，程序会自动尝试连接 iOS 设备相关通道。
2. 点击“选择进程”，从进程列表中选中需要监测的目标。
3. 勾选需要采集的项目，例如“帧率”、“CPU”、“GPU”。
4. 点击“开始监测”，开始采集并生成性能文件。
5. 需要结束时点击“停止监测”，保存当前采集结果。
6. 如果要分析历史数据，先选择 `.performance` 文件，再点击“性能分析”。

## 代码逻辑概览

### 1. 设备连接
程序启动后，会尝试通过本机 tunnel 服务连接 iOS 设备，并读取设备信息，包括地址、端口和 UDID。

### 2. 进程选择
连接成功后，程序会拉取设备进程列表。用户选择某个进程后，程序会把该进程名作为当前监测目标，并据此生成输出文件名。

### 3. 实时采集
采集过程中会持续读取 syslog 中的性能数据，使用正则表达式提取类似 `metal-HUD` 的数据片段，然后：

- 计算实时 FPS
- 计算进程占用 GB 数值
- 追加写入本地性能文件
- 更新界面中的实时曲线和数值标签

### 4. 离线分析
对已保存的 `.performance` 文件进行解析后，程序会统计：

- 平均帧率
- 低帧率分位数
- 帧率损失比例
- 卡顿率

并绘制散点图便于观察波动情况。

## 依赖环境

- Python 3.x
- PyQt5
- numpy
- matplotlib
- ios_device 相关依赖

如果缺少依赖，请先安装对应的 Python 包。

## 目录说明

- `realease.py`：主程序入口
- `main.py`：示例/测试窗口
- `*.performance`：性能采集结果文件
- `log.txt`：运行日志
- `ios_helper/` 下其他脚本：辅助测试与日志处理脚本

## 备注

- 当前仓库已配置忽略日志和部分临时文件。
- 若程序无法连接设备，请检查本机 iOS tunnel 服务和相关环境是否正常。
